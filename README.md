# 🌐 Personal Portfolio Website

A simple and professional **Personal Portfolio Website** created using **HTML5**. This project showcases personal information, technical skills, projects, education, and contact details in a structured and user-friendly format.

## 📌 Project Overview

The purpose of this project is to create a personal portfolio website using only HTML. It demonstrates the use of semantic HTML elements, internal navigation, images, lists, links, and form validation.

## ✨ Features

* 🏠 Home section
* 👨‍💻 About Me section
* 🛠️ Technical and Soft Skills section
* 💻 Projects section
* 🎓 Education section
* 📩 Contact form
* 🔗 GitHub and LinkedIn links
* 🖼️ Profile image with proper `alt` text
* 🧭 Internal navigation links
* ✅ HTML form validation
* 📱 HTML5 responsive viewport setup
* ♿ Semantic and accessible HTML structure

## 🛠️ Technologies Used

* **HTML5**
* **VS Code**
* **Web Browser**

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Add Your Profile Image

Place your profile image inside the project folder and name it:

```text
profile.jpg
```

### 4. Run the Website

Open `index.html` in any modern web browser.

You can also use the **Live Server** extension in VS Code.

## 📝 Sections Included

### 🏠 Home

Contains the portfolio owner's name, professional introduction, and navigation menu.

### 👤 About Me

Provides information about the person, interests, career objective, and background.

### 🛠️ Skills

Displays technical and soft skills using HTML unordered lists.

### 💻 Projects

Showcases completed or ongoing projects with brief descriptions.

### 🎓 Education

Provides educational and learning information.

### 📩 Contact

Contains a contact form with fields for:

* Full Name
* Email Address
* Subject
* Message

HTML validation attributes such as `required`, `minlength`, `maxlength`, and `type="email"` are used.
